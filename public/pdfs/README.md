# PDFs des Expéditions

Ce dossier contient les brochures PDF détaillées pour chaque expédition.

## Structure

- `jyrgalan.pdf` - Programme détaillé de la Vallée de Jyrgalan
- `song-kul.pdf` - Programme détaillé du Lac Song Kul

## Instructions

Pour ajouter ou mettre à jour un PDF d'expédition :

1. Placez votre fichier PDF dans ce dossier (`public/pdfs/`)
2. Nommez-le selon l'ID de l'expédition (ex: `jyrgalan.pdf`)
3. Le lien sera automatiquement disponible sur la carte de l'expédition

## Format recommandé pour les PDFs

Chaque PDF devrait contenir :
- Titre de l'expédition
- Durée et difficulté
- Itinéraire jour par jour
- Hébergements
- Équipement nécessaire
- Prix détaillé (inclus/non inclus)
- Conditions de réservation
- Contact
